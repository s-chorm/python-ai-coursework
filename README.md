# Python AI Coursework
Contains all AI course labs and projects that have been completed in Python.

# Information
All subfolders are categorized into Units and include both Python files and Jupyter Notebooks. The "requirements.txt" lists all libraries required to run some Python files.

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/s-chorm/python-ai-coursework.git

2. Install the dependencies:
   ```pip install -r requirements.txt```

3. Run the Streamlit app (replace app_title with file you want to run):
   ```streamlit run app_title.py```
